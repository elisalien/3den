# :3den

> Page de présentation du projet de soirée :3den — pop culture, anime et jeux vidéo à la Rayonne.

![Platform](https://img.shields.io/badge/platform-Web-informational) ![Stack](https://img.shields.io/badge/stack-HTML%20%2F%20CSS%20%2F%20JS-orange)

## À propos

:3den (« Projet de soirée ») est une page web mono-fichier qui rassemble le dossier de travail d'un projet de soirées autour de la pop culture, de l'anime et des jeux vidéo, à la Rayonne. Elle sert de support de présentation pour le concept, les partenaires et les idées de line-up.

## Fonctionnalités

- Sections **Le projet** (concept, activités, date), **Partenaires** (partenaires, jurys cosplay) et **Line-up** (idée de line-up, puis artistes par pays : France, Allemagne, UK, USA, Japon).
- Barre latérale de navigation avec surlignage de la section active au défilement.
- Mise en page responsive (tablette et mobile) avec menu repliable.
- Cartes artistes, tags et statuts des partenaires.

## Installation

Aucune installation : ouvre `index.html` dans un navigateur.

## Utilisation

Le contenu se modifie directement dans `index.html` (textes des sections, cartes artistes, partenaires). Navigue entre les sections via la barre latérale ou, sur mobile, via le bouton de menu.

## Stack technique

HTML, CSS, JavaScript vanilla (IntersectionObserver pour la navigation).
